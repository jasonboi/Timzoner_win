# Windows 系统时区托盘工具

Status: ready-for-agent

## Problem Statement

用户需要反复切换 Windows 系统时区。现有系统设置入口步骤多，希望通过常驻托盘菜单快速选择收藏时区，同时维持低 CPU 和内存占用。

## Solution

在 Windows 11 x64 上提供一个普通权限托盘应用。右键菜单列出收藏时区，配置窗口管理收藏、主题和开机启动。最终以按用户安装且携带运行时的安装程序交付。

## User Stories

1. 作为用户，我希望从托盘右键菜单选择收藏时区，以便快速切换系统时区。
2. 作为用户，我希望看到 Windows 实际当前时区，以便确认切换结果。
3. 作为首次使用者，我希望当前时区自动进入收藏，以便有一个有效的初始选项。
4. 作为用户，我希望搜索系统可用时区的名称和 ID，以便找到所需区域。
5. 作为用户，我希望添加收藏时区，以便将其放入快捷菜单。
6. 作为用户，我希望重复收藏得到提示，以便避免菜单重复。
7. 作为用户，我希望删除收藏，以便减少无用条目。
8. 作为用户，我希望调整收藏顺序，以便把常用项放在前面。
9. 作为用户，我希望保存后菜单立即更新，以便不用重启应用。
10. 作为用户，我希望取消编辑保留原设置，以便放弃误操作。
11. 作为用户，我希望重启后保留收藏、顺序和主题，以便继续使用。
12. 作为用户，我希望选择浅色、深色或跟随系统，以便匹配使用环境。
13. 作为用户，我希望关闭配置页后继续驻留，以便仍可快速切换。
14. 作为用户，我希望明确退出程序，以便结束常驻进程。
15. 作为用户，我希望自行开启或关闭开机启动，以便控制后台程序。
16. 作为用户，我希望切换失败时看到原因，以便判断是否需要授权或修改系统设置。
17. 作为用户，我希望提权需要自己发起，以便控制管理员操作。
18. 作为用户，我希望取消提权后仍能使用配置页，以便继续管理收藏。
19. 作为用户，我希望夏令时遵循 Windows 规则，以便当地时间正确。
20. 作为用户，我希望自动时区覆盖手动选择时得到提示，以便决定如何配置 Windows。
21. 作为用户，我希望其他程序更改时区后菜单仍显示实际状态，以便避免误判。
22. 作为用户，我希望配置损坏后有恢复提示，以便找回设置。
23. 作为用户，我希望配置保存失败时保留已保存数据，以便避免丢失收藏。
24. 作为用户，我希望重复打开只出现一个实例，以便避免多个托盘图标。
25. 作为用户，我希望 Explorer 重启后托盘图标恢复，以便不必重启应用。
26. 作为用户，我希望通过键盘和高 DPI 界面操作，以便适应不同设备。
27. 作为用户，我希望安装时无需另装运行时，以便直接使用。
28. 作为用户，我希望升级保留配置，卸载清理启动项，以便维护安装状态。
29. 作为用户，我希望程序闲置时几乎不占用 CPU，并满足内存预算，以便长期常驻。

## Implementation Decisions

- 使用 C#、.NET 10 LTS 和 WinForms，简体中文界面。按用户安装的 Inno Setup 安装程序携带 x64 运行时。
- 托盘消息循环常驻，配置窗口按需创建并在关闭时释放。采用单实例和系统事件通知，不持续轮询。
- 一个应用控制器提供统一行为入口，协调配置存储、系统时区适配器和开机启动适配器。
- 收藏使用有序且去重的 Windows 时区 ID。主题支持 system、light、dark，默认 system。首次仅收藏当前时区，开机启动默认关闭。
- 配置具有 schema 版本，先校验再原子写入，保留备份。损坏数据可恢复，较新 schema 不静默覆盖。空收藏有效，失效 ID 禁用切换并允许删除。
- 配置窗口使用编辑草稿，保存成功后更新菜单，取消不修改已提交状态。开机启动与文件存储部分失败时报告实际状态。
- 修改系统时区使用 Windows 原生 API，保留动态夏令时规则，不修改系统 UTC 时间。切换完成后读回验证，串行处理切换请求。
- 普通权限常驻。权限不足时由用户发起一次性提权重试，辅助模式仅接受有效时区 ID。拒绝或取消授权不会终止普通配置功能。
- 自动时区可能覆盖手动选择时提供系统设置入口，不自动关闭系统自动时区。检测失败保留未知状态。
- 在切换前及菜单打开前刷新实际当前时区。当前时区不在收藏时也明确显示。
- 安装升级保留配置，卸载清理自身程序与启动项，并允许用户选择删除配置。

## Testing Decisions

测试从统一应用行为入口验证可见状态、返回结果与持久化效果。替换系统调用和存储边界，普通自动化测试不修改开发机时区。项目为新仓库，没有既有测试可复用。

覆盖收藏增删排序、去重、保存与取消、损坏恢复、未知 schema、保存失败、切换成功与失败、读回不一致、权限拒绝、取消提权、重复请求、失效时区和外部变化。

Windows 人工验收覆盖真实系统切换、UAC、系统自动时区、夏令时规则、主题、DPI、单实例、托盘恢复、安装升级卸载与开机启动。真实修改前记录原时区，完成后恢复并验证。

Release 托盘静置 300 秒，CPU 时间按墙钟时间和逻辑处理器数归一化，平均不超过 0.1%。专用内存峰值在托盘静置时不超过 60 MiB，配置页打开并预热后的采样中不超过 100 MiB。资源目标未测量前不得声明通过。

## Out of Scope

跨平台、Windows 10 或 ARM64 的支持承诺、世界时钟面板、位置自动切换、计划任务式切换、云同步、账号、遥测、自动更新、自定义夏令时规则和代码签名证书采购。
