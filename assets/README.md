# Application icon

Timzoner.ico contains the final clock and globe icon at 16, 20, 24, 32, 48, 64, 128 and 256 pixels. Frames from 64 pixels up are stored as PNG to keep the executable small, and smaller frames stay as bitmaps. The filled artwork was supplied by the user and cropped to a circle. Preparation images and scripts remain local.

licenses/dotnet-LICENSE.txt contains the .NET license for the apphost included with the application. The Desktop Runtime is installed separately.
