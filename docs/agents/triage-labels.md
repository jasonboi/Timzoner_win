# Triage labels

| 技能角色 | 本地 Status 值 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 需要评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格齐备，可以实施 |
| ready-for-human | ready-for-human | 需要人工执行 |
| wontfix | wontfix | 不实施 |

技能要求应用标签时，更新任务文件的 `Status:`。本项目无需创建 GitHub 标签。
