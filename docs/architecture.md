# 技术方案

## 栈与取舍

| 层 | 选择 | 理由与代价 |
| --- | --- | --- |
| 应用 | C# + .NET 10 LTS + WinForms | 托盘和桌面控件可直接使用，运行时有内存成本，须按预算验收 |
| 时区操作 | Windows API | 读取系统时区规则，显式处理修改权限与错误 |
| 配置 | System.Text.Json + 用户本地文件 | 配置规模小，无需数据库 |
| 安装 | Inno Setup | 按用户安装、快捷方式、升级和卸载，构建时核对所用版本的分发条款 |
| 测试 | .NET 测试项目，优先 xUnit | 从应用行为入口测试成功和失败，不实际更改开发机时区 |

本项目仅需简单配置窗口。相比引入 WebView 或浏览器运行时，WinForms 可减少运行层次。C++ Win32 有更直接的资源控制，但窗口、主题与字符串处理的实现成本更高。选择 WinForms 后先验证常驻资源预算，再扩展配置界面。

## 进程与界面

单个普通权限进程以 ApplicationContext 驱动消息循环，使用 NotifyIcon 和右键菜单。配置窗体按需创建，关闭后释放并清除引用。退出时释放图标、窗口和事件订阅。

同一用户会话仅运行一个实例，第二次启动唤起已有配置窗口。处理 Explorer 重启后的托盘恢复，不采用持续轮询或常驻后台服务。

通过系统变更通知刷新状态，在打开菜单前重新读取当前系统时区，避免缓存过期。主题变化和时区变化使用事件驱动。收藏菜单不持续刷新世界时钟。

## 应用行为入口

一个应用控制器协调读取当前状态、编辑和保存配置、切换时区与报告结果。界面只展示状态并转交用户操作。

系统适配器封装可用时区、当前时区、修改时区和权限处理。配置存储与开机启动通过窄边界访问操作系统。测试从控制器入口观察返回状态与持久化结果，替换这些外部边界。

## 时区与权限

收藏持久化 Windows 时区 ID，展示名称来自系统目录。每次切换都按 ID 重新取得有效规则，保持 Windows 的动态夏令时规则。

在进程具备该权限时，临时启用 SeTimeZonePrivilege，调用 SetDynamicTimeZoneInformation，并恢复先前的令牌权限状态。API 返回成功后重新读取当前时区，匹配目标才报告成功。

权限不足时，由用户明确选择提权重试。短生命周期的提权辅助模式只接受有效的系统时区 ID，不接受任意命令、路径或配置写入指令。它完成一次切换后退出，普通进程重新读取系统状态确认结果，不依赖辅助模式的文字输出推断成功。

切换期间串行处理请求，禁用重复提交。对 UAC 取消、权限被策略拒绝、无效 ID 和系统状态未匹配分别展示可理解的结果。

自动时区检测属于辅助提示，检测不可用时不得把未知显示为关闭。手动切换后被 Windows 再次覆盖时，展示实际当前状态和系统设置入口。程序不更改系统自动时区设置。

## 配置与生命周期

配置位于 `%LOCALAPPDATA%\Timzoner\settings.json`，包含 schemaVersion、favoriteTimeZoneIds、theme、language 和 startWithWindows。收藏是有序且去重的 Windows 时区 ID 列表。language 支持 zh-CN 与 en，旧配置缺少该字段时使用简体中文。

配置页编辑草稿，保存时校验 ID 与枚举值。先将新配置写入同目录临时文件，成功后原子替换并保留上一版备份。失败时不显示保存成功，不更新已提交状态。

缺少文件时初始化当前时区。配置损坏时保留损坏副本并尝试备份，无法恢复则提示并使用默认配置。较新且不支持的 schema 不被静默覆盖。系统不再提供的收藏保留供用户删除，并禁用切换。

开机启动采用当前用户启动注册项，显式开启才写入，关闭和卸载时清理本应用条目。若写入失败，配置页显示实际结果并允许重试。整个操作成功后才报告保存完成，部分失败必须明确指出。

## 主题与可访问性

标准 WinForms 控件使用显式浅色与深色配色，标题栏通过 DWM 跟随主题。避免运行时切换框架色彩模式导致已有原生控件与新控件颜色不同。禁用按钮单独绘制可读文字，高对比度模式使用系统颜色。保留键盘操作、焦点提示和高 DPI 缩放，窄窗口将两组时区列表上下排列。列表采用可变行高绘制，长名称自动换行。收藏按钮随宽度换行，高度不足时整页滚动，更新内容尺寸后同步刷新滚动范围。

语言切换按钮位于外观下一行，即时预览中文与英文。保存时持久化语言，取消时恢复已提交语言。托盘、配置控件和应用提示跟随语言，Windows 自身异常详情仍由系统提供。英文时区列表显示标准 UTC 偏移和稳定的 Windows 时区 ID，中文显示系统提供的区域名称。偏移用于时区目录标签，实际夏令时仍由 Windows 规则决定。

## 发布

发布目标为 win-x64 的自包含目录，再交给 Inno Setup 压缩打包。首版关闭裁剪，不依赖 Native AOT。运行时随包分发，运行时安全更新通过重新发布安装包交付。

按用户安装到 LocalAppData 下的 Programs 目录，普通安装流程不请求管理员权限。升级和卸载先通过命名事件请求实例退出，并检查退出结果。切换进行中或退出超时时中止操作，保留程序文件。卸载删除程序、快捷方式和开机启动项，默认保留用户配置并允许用户选择删除。

安装包未签名时可能出现 Windows 发布者或 SmartScreen 提示。公开稳定发行前另行决定签名方案，不声称安装包已经可信签名。
