# 采用 .NET 10 WinForms 构建托盘工具

首版只支持 Windows 11 x64，界面以托盘菜单和简单配置窗口为主，因此选择 C# 与 .NET 10 WinForms，以减少界面和系统集成的开发成本。相比 C++ Win32，该方案接受托管运行时的资源成本，并以明确的 CPU 和内存预算验收。发布采用自包含安装包，接受更大的分发体积，换取无需用户单独安装运行时。

2026-10-10，用户改选共享 .NET 10 Desktop Runtime x64，以减小应用安装包和安装目录。Windows 11 x64、C# 和 WinForms 的选择保持不变。缺少运行时时提供系统启动错误提示与官方下载入口，README 写明依赖。运行时首次安装仍占磁盘空间，后续桌面应用可以共用。
