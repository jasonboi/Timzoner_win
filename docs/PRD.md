# Timzoner 产品需求

2026-10-10，经用户确认。

## 目标

用户需要在 Windows 上快速切换常用系统时区，避免反复进入系统设置。程序常驻系统托盘，尽量减少 CPU 和内存占用，最终交付 Windows 安装程序。

## 用户流程

首次启动后出现托盘图标。右键菜单列出收藏时区，勾选与系统当前时区相符的条目，同时提供打开配置页和退出入口。没有收藏时，菜单保留配置入口。

用户在配置页搜索 Windows 可用时区，将需要的时区加入收藏，通过上移和下移调整顺序，删除不再使用的收藏。添加同一时区时提示已经存在。保存成功后立即更新菜单，取消编辑保留原配置。

用户选择收藏时区后，程序读取 Windows 返回结果并再次读取当前时区。只有确认匹配才显示切换成功，失败时保留真实当前状态并说明原因。选择已经生效的时区不重复执行系统修改。

配置页提供主题和开机启动选项。关闭配置窗口后程序继续驻留托盘，选择退出才终止进程。

## 系统行为

夏令时遵循 Windows 时区规则，不把固定 UTC 偏移作为时区。程序不修改系统 UTC 时间。

程序以普通用户运行。缺少修改权限时提供由用户发起的提权重试，用户取消后仍可使用收藏配置。组织策略阻止修改时显示失败，不尝试绕过策略。

Windows 自动时区可能覆盖手动切换。发现冲突或检测到自动时区开启时，提示打开系统日期和时间设置，由用户决定是否关闭自动时区。

## 资源目标

以下为资源验收目标。

- Release 托盘静置 5 分钟，按整机逻辑处理器数归一化的平均 CPU 不超过 0.1%。
- 托盘空闲专用内存不超过 60 MiB。
- 配置页打开时专用内存不超过 100 MiB。

验收记录保留本地，不纳入仓库。安装包使用共享运行时以减少每份应用的磁盘占用。

## 不包含

不包含跨平台、世界时钟面板、定时切换、云同步、账号、遥测、后台自动更新和自定义夏令时规则。代码签名证书采购不在本轮范围内。

## 本轮交付

交付托盘切换、收藏配置、中英文切换、浅色与深色主题、按用户安装包和资源验收记录。托盘菜单提供手动检查更新。检查时读取 GitHub 最新 Release，发现更高版本后经用户确认下载安装包，按 Release 公布的 SHA-256 校验通过后静默安装并重新启动，不在后台自动检查。PRD 保存在仓库，本地实施任务与 AGENTS.md 不纳入 Git。
