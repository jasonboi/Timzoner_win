# 验收计划

## 当前结果

当前尚无应用实现，以下检查均未执行。仓库初始化与文档检查不代表应用功能或资源目标达标。

## 行为验证

通过应用控制器的公开操作验证外部行为，系统调用使用替身隔离。

- 首次配置、空收藏、重复添加、顺序调整、删除和重启后的持久化。
- 取消编辑不提交，保存失败保留已提交状态，损坏配置恢复，未知 schema 不被覆盖。
- 切换成功且系统读回匹配、系统返回失败、读回不匹配、当前时区无须修改、失效 ID、连续点击和提权取消。
- 开机启动写入失败明确报告，实际状态与显示一致。
- 外部时区变化后菜单显示真实状态，不把收藏第一项当作当前时区。

## Windows 人工验收

在专用测试机或用户明确授权的会话中执行真实切换，记录原时区并在测试结束后恢复和验证。

- 标准用户与管理员账号下切换，覆盖没有时区权限的受限环境以及 UAC 取消。
- 检查有夏令时和无夏令时的区域，验证遵循系统规则，不通过修改电脑日期来测试。
- Windows 自动时区开启、检测不可用和手动切换被覆盖时，提示与实际状态一致。
- 浅色、深色、跟随系统、高对比度、键盘导航及 100%、150%、200% DPI。
- 关闭配置窗口继续驻留、重复启动只有一个实例、Explorer 重启后图标恢复、退出后图标消失。
- 全新安装、覆盖升级、用户安装目录含空格或中文、卸载和配置保留或删除。
- 默认不自启，开启后下次登录启动，关闭后不启动，卸载后无残留启动项。

## 资源测量

使用 Windows 11 x64 Release 自包含发布版本，无调试器。记录系统版本、CPU、逻辑处理器数、内存、应用提交版本和构建设置。

1. 启动并预热 30 秒，保持托盘空闲，关闭配置页。
2. 连续 300 秒每秒采样一次进程专用内存，记录峰值、平均值和工作集。以专用内存峰值不超过 60 MiB 为通过条件。
3. 读取采样前后的 TotalProcessorTime，CPU 百分比为 CPU 时间差除以实际墙钟时间差和逻辑处理器数，再乘 100。平均值必须不超过 0.1%。
4. 打开配置页，搜索和编辑收藏后静置 30 秒，再采样 60 秒。专用内存峰值必须不超过 100 MiB。
5. 重复打开和关闭配置页 20 次，观察是否持续增长。关闭后再测 300 秒，托盘预算仍须通过。
6. 单独记录安装包大小、安装目录大小和首次启动时间，作为比较数据。

专用内存使用 PrivateMemorySize64，不与任务管理器默认工作集列混用。安装程序、测试工具和一次性提权进程不计入托盘静置进程指标，但须单独记录异常峰值。

预算未通过时记录原始数据，先检查未释放窗口、事件订阅和后台任务。未经重新确认不得通过更换指标或放宽预算宣布达标。
