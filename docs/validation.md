# 验收记录与计划

## 当前结果

2026-10-10，0.1.0 的 Release 自包含版本完成 41 项自动化测试，覆盖控制器行为、配置持久化、语言兼容与 UTC 偏移格式。使用 .NET SDK 10.0.401、.NET / Windows Desktop Runtime 10.0.12、Inno Setup 6.7.3，关闭裁剪和 Server GC，无调试器。

测试机器为 Windows 11 x64 build 26200，AMD Ryzen AI 9 HX 370，24 个逻辑处理器，系统报告物理内存 33,412,722,688 字节。

已执行真实时区切换并读回验证，从 China Standard Time 切至 UTC，再恢复 China Standard Time。原始和恢复后的 DynamicDaylightTimeDisabled 均为 false。该次切换获得用户授权，之后的界面与安装验收没有修改系统时区。

界面自动验收使用独立配置，验证搜索、添加、去重、上移与下移、删除、取消、保存后重新打开、浅色与深色预览。保存检查同时核对 JSON 中的收藏顺序、主题和语言。语言按钮位于外观下一行，英文列表保留 UTC 偏移，取消会恢复原语言。窗口反复开关 20 次，第二次启动仍复用同一进程。

回归测试将窗口缩至 380×460 逻辑像素，确认两组列表不超出可用宽度，收藏按钮自动换行，滚动后语言和保存按钮完整可用。列表长名称按可用宽度换行。此前内容尺寸变化后原生滚动范围仍保留旧值，已在更新尺寸后同步执行布局。截图位于 `artifacts/settings-light.png`、`artifacts/settings-dark.png`、`artifacts/settings-english.png`、`artifacts/settings-small-top.png` 和 `artifacts/settings-small-bottom.png`。

安装包已通过以下检查。

- 按用户安装到含中文与空格的目录，随包提供 .NET 许可证与第三方声明。
- 模拟实例忙碌，卸载退出且保留程序及安装登记。
- 正在运行时覆盖升级，旧实例退出，配置内容保留。
- 正在运行时静默卸载，实例退出，程序文件、安装登记和本应用启动项被清理，配置保留。

验收在独立配置目录中执行，启动项原值在测试后恢复。安装包为 37,502,793 字节，发布目录为 123,399,439 字节。安装后首次启动到配置文件出现的时间记录在 `artifacts/installer-checks.json`，此时间不代表托盘完全可交互的耗时。

## 已测资源

专用内存按 PrivateMemorySize64 计量，CPU 按所有逻辑处理器归一化。预热 30 秒，每秒采样一次。0.1% CPU 上限用于托盘静置场景，配置页按已确认规格检查 100 MiB 内存上限，同时记录 CPU 供比较。原始记录保存在 `artifacts/core-resources.json`、`artifacts/config-resources.json` 和 `artifacts/final-resources.json`。构建使用 `./scripts/Build.ps1 -Installer`，界面与资源验收使用 `./scripts/Test-Acceptance.ps1`。构建工具可通过 `./scripts/Initialize-Tools.ps1` 初始化。

| --- | --- | --- | --- | --- |
| 核心托盘版本 | 305.55 秒 | 0.01342% | 27.76 MiB | 通过 |

托盘采样后仅调整列表滚动条和文字测量宽度，随后重新构建并复测配置页。列表固定保留滚动条空间，避免条目重新加入时测量宽度变化导致末行截断。

## 行为验证

通过应用控制器的公开操作验证外部行为，系统调用使用替身隔离。

- 首次配置、空收藏、重复添加、顺序调整、删除和重启后的持久化。
- 取消编辑不提交，保存失败保留已提交状态，损坏配置恢复，未知 schema 不被覆盖。
- 切换成功且系统读回匹配、系统返回失败、读回不匹配、当前时区无须修改、失效 ID、连续点击和提权取消。
- 开机启动写入失败明确报告，实际状态与显示一致。
- 外部时区变化后菜单显示真实状态，不把收藏第一项当作当前时区。

## Windows 人工验收

在专用测试机或用户明确授权的会话中执行真实切换，记录原时区并在测试结束后恢复和验证。

- 标准用户与管理员账号下切换，覆盖没有时区权限的受限环境以及 UAC 取消。
- 检查有夏令时和无夏令时的区域，验证遵循系统规则，不通过修改电脑日期来测试。
- Windows 自动时区开启、检测不可用和手动切换被覆盖时，提示与实际状态一致。
- 浅色、深色、跟随系统、高对比度、键盘导航及 100%、150%、200% DPI。
- 关闭配置窗口继续驻留、重复启动只有一个实例、Explorer 重启后图标恢复、退出后图标消失。
- 全新安装、覆盖升级、用户安装目录含空格或中文、卸载和配置保留或删除。
- 默认不自启，开启后下次登录启动，关闭后不启动，卸载后无残留启动项。

## 资源测量

使用 Windows 11 x64 Release 自包含发布版本，无调试器。记录系统版本、CPU、逻辑处理器数、内存、应用提交版本和构建设置。

1. 启动并预热 30 秒，保持托盘空闲，关闭配置页。
2. 连续 300 秒每秒采样一次进程专用内存，记录峰值、平均值和工作集。以专用内存峰值不超过 60 MiB 为通过条件。
3. 读取采样前后的 TotalProcessorTime，CPU 百分比为 CPU 时间差除以实际墙钟时间差和逻辑处理器数，再乘 100。平均值必须不超过 0.1%。
4. 打开配置页，搜索和编辑收藏后静置 30 秒，再采样 60 秒。专用内存峰值必须不超过 100 MiB。
5. 重复打开和关闭配置页 20 次，观察是否持续增长。关闭后再测 300 秒，托盘预算仍须通过。
6. 单独记录安装包大小、安装目录大小和首次启动时间，作为比较数据。

专用内存使用 PrivateMemorySize64，不与任务管理器默认工作集列混用。安装程序、测试工具和一次性提权进程不计入托盘静置进程指标，但须单独记录异常峰值。

预算未通过时记录原始数据，先检查未释放窗口、事件订阅和后台任务。未经重新确认不得通过更换指标或放宽预算宣布达标。
